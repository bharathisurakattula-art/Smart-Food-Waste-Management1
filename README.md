# Smart Food Waste Management

## Overview
The Smart Food Waste Management project is a web application designed to help users manage food waste effectively. It provides functionalities for users to register, log in, donate food, volunteer for food distribution, and manage administrative tasks.

## Project Structure
```
Smart-Food-Waste-Management
├── index.html          # Main entry point for the web application
├── pages
│   ├── login.html     # HTML structure for user login
│   ├── register.html  # HTML structure for user registration
│   ├── donor.html     # HTML layout for managing donations
│   ├── volunteer.html  # HTML structure for volunteer opportunities
│   └── admin.html     # HTML structure for admin management
├── css
│   ├── home.css       # Styles for the main index page
```

## Features
- **User Authentication**: Users can register and log in to access their accounts.
- **Donation Management**: Donors can manage their donations easily through a dedicated page.
- **Volunteer Opportunities**: Users can sign up for various volunteer opportunities.
- **Admin Management**: Administrators have access to management features for overseeing the application.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open `index.html` in your web browser to view the application.
3. Ensure all CSS and JavaScript files are linked correctly for full functionality.
